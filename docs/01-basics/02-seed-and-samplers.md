## 📦 板块一：画布规格块（空 Latent 图像节点）

在画布左下角，`空Latent图像 (SD3)` 节点负责设定画框尺寸与并发生成策略：

```text
┌──────────────────────────────────────────────────────────┐
│                   空Latent图像 (SD3)                     │
│  ├─ 宽度 (width)       ➔ 1536                            │
│  ├─ 高度 (height)      ➔ 648 (21:9 电影画幅)             │
│  └─ 批量大小 (batch)   ➔ 1 (单次并发生成几张)            │
└──────────────────────────────────────────────────────────┘
```

### 1️⃣ 宽与高（画幅比例调校）
* **大白话**：决定成片的构图视角。默认正方形为 `1024 × 1024`，电影级宽屏为 **`1536 × 648` (21:9)** 或 `1344 × 768` (16:9)。
* **动手实操**：
  1. 若 `宽度` / `高度` 左侧连着浅绿线，**按住绿线向外一甩拔掉断开**。
  2. 双击数字，将 `宽度` 改为 **`1536`**，`高度` 改为 **`648`**，打破默认的正方形构图！

### 2️⃣ 批量大小 (`batch_size`)：并发一锅出 vs 队列排队跑
* **核心机制对比**：

| 对比维度 | `批量大小` (Batch Size) | 右上角 `任务队列` (Queue Count) |
| :---: | :---: | :---: |
| **作画方式** | **一锅炖（显卡同时并发画多张）** | **排队跑（画完一张自动接着画下一张）** |
| **出图速度** | 🚀 极快（充分榨干显卡并发算力） | ⏳ 线性累加（时间成倍增加） |
| **显存占用** | 💥 **显存成倍暴涨！**<br>(设为 4 显存可能从 8G 飙到 16G+) | 🛡️ **显存完全不变！**<br>(永远只占 1 张图的显存) |
| **爆显存风险** | 高（显存不足容易 CUDA OOM 崩溃） | 零风险（极度稳健安全） |

* **硬件分档配置建议**：
  * 🚀 **旗舰显卡 (RTX 5080/4090)**：跑 Turbo 极速模型时，可豪气将 `批量大小` 设为 **`2` 或 `4`**，1~3 秒直接并发产出 4 张大片！
  * ⚡ **主流显卡 (RTX 4070 12GB 及同级)**：建议保持 **`批量大小 = 1`**，通过右上角加队列排队挂机，最稳妥安全。
  * 🎬 **视频生成时代 (Wan 2.2)**：**严禁调大批量大小，必须死死锁定为 1**！

## 📦 板块二：语义指令与负向静音块（CLIP + 条件零化）

在画布中央，负责将人类意图精准传达给画家的神经中枢：

```text
【CLIP 文本编码 (正向词)】 ──(黄色条件线)────────────────────────────> 【K 采样器: 正面条件】
【CLIP 文本编码 (正向词)】 ──(黄色条件线)──> 【条件零化】 ──(清零负向)──> 【K 采样器: 负面条件】
```

### 1️⃣ 中文提示词（写实光影与材质注入）
* **原理**：Qwen 3.4B 语言模型具备强大的原生中文理解能力，支持细腻的光影、物理材质与镜头描述。
* **动手实操**：
  点击黑色大框内部，按 `Ctrl + A` 全选清空，替换填入以下带有电影写实质感的中文提示词：
  ```text
  一只身穿精细机械外骨骼铠甲的白猫，坐在雨后赛博朋克街道上，路灯与水坑霓虹灯倒影，写实照片，电影级光影，8k解像度
  ```

### 2️⃣ 条件零化 (`ConditioningZeroOut`)：负向条件静音器
* **为什么插在下方？**
  * 传统 SD 1.5/SDXL 作画时，采样器每一步都需要同时计算正向词与负向词（差分引导），耗时翻倍。
  * 而 Z-Image-Turbo / FLUX 等现代极速蒸馏模型收敛能力极强，**完全不需要写冗余的负向提示词**！
  * `条件零化` 节点将负向条件数学归零注入 K 采样器的 `负面条件` 接口，使采样器省去一半的负向计算量，全速输出高质感画面！

## 📦 板块三：画笔作画中枢（K 采样器节点）

在画布右侧，`K 采样器` 是最核心的去噪作画引擎，5 大参数决定了画家的作画手法：

```text
┌───────────────────────────────────────────────────────────┐
│                    K 采样器 (KSampler)                    │
│  ├─ 种子 (seed)               ➔ 8888 (画面的基因灵感)    │
│  ├─ 生成后控制 (control)      ➔ fixed (锁定/随机策略)    │
│  ├─ 步数 (steps)              ➔ 8 (去噪雕琢轮数)         │
│  ├─ cfg                       ➔ 1.0 (听话程度与引导尺度) │
│  ├─ 采样器名称 (sampler_name) ➔ res_multistep (画笔算法) │
│  ├─ 调度器 (scheduler)        ➔ simple (步长节奏曲线)    │
│  └─ 降噪 (denoise)            ➔ 1.00 (从零作画/垫图重绘) │
└───────────────────────────────────────────────────────────┘
```

### 1️⃣ Seed（随机种子）与 4 种控制策略
* **大白话**：Seed 是画面的**“基因灵感编号”**。只要 Seed 固定，人物长相、五官构图、机位角度与光线朝向就会 **100% 锁定不变**！
* **💡 4 种控制策略大白话**：
  * **`fixed`（固定）**：死死锁定数字。专用于**微调局部词汇、固定角色长相与多镜头一致性**。
  * **`randomize`（随机）**：每次运行自动抽奖换新数字。用于寻找全新灵感。
  * **`increment`（递增）** / **`decrement`（递减）**：每次运行数字自动 `+1` / `-1`。
* **动手实操**：
  1. 若 `种子` 左侧连着绿线，按住绿线向外一甩拔掉断开。
  2. 双击将 `种子` 填入固定数值：**`8888`**。
  3. 将 `生成后控制` 下拉菜单切换选择为 **`fixed`（固定）**！

### 2️⃣ Steps（去噪步数）：画家的“雕琢轮数”
* **原理**：AI 消除噪点还原画面的循环次数。
* **规律**：Z-Image-Turbo / FLUX 等蒸馏模型仅需 **8 步**（或 4 步）即可极速收敛；传统 SDXL 则需 25~30 步。

### 3️⃣ CFG（引导尺度）：画家的“听话程度”
* **规律**：极速流匹配/蒸馏模型中**必须固定设为 `1.0`**（完全依靠模型内在先验快速成画）；传统模型通常为 6.0~8.0。

### 4️⃣ Sampler（采样器）与 Scheduler（调度器）：画手的“运笔技法”与“作画节奏”

这是很多初学者最容易困惑的两个下拉菜单。其实只要记住一个核心形象比喻：
* **`采样器 (Sampler)` = 画家的【运笔技法 / 手法算法】**：决定从噪点中削出清晰画面的数学求解路径。
* **`调度器 (Scheduler)` = 画家的【作画节奏表 / 进度计划】**：决定每一轮去噪到底擦除多少百分比的噪点。

---

#### 🖌️ 3 大主流【采样器 (Sampler)】大白话拆解：

1. **`res_multistep`（多步重启采样器 - 本课 Z-Image 官方钦定 👑）**：
   * **特点**：专为现代 **极速流匹配 (Flow Matching)** 模型定制。
   * **为什么选它**：在 4~8 步的极短步数内，它能同时结合前几步的历史运动趋势进行综合插值推算，既快又稳，彻底杜绝画质崩溃与色块断层！
2. **`euler`（欧拉采样器 - FLUX / SD3 首选 🚀）**：
   * **特点**：最经典的单步切线推进，下笔最直接利落，计算开销最小。
   * **为什么选它**：与高度蒸馏的极速模型（如 FLUX.1 Schnell/Dev）天然绝配。
3. **`dpmpp_2m`（DPM-Solver++ 2M - SDXL 经典万金油 🎨）**：
   * **特点**：传统扩散模型时代的二阶经典，纹理与细节细腻度极高，是 SD 1.5 和 SDXL 的绝对主力画笔。

---

#### ⏱️ 3 大主流【调度器 (Scheduler)】大白话拆解：

1. **`simple`（简单线性 - 现代流匹配黄金搭档 ⭐）**：
   * **特点**：匀速、等步长地消除噪点。
   * **为什么选它**：现代 Flow Matching（Z-Image-Turbo、FLUX、Wan 2.2）在数学上沿着一条平直的速度向量场推进，因此匀速线性的 `simple` 完美贴合模型的物理本性。
2. **`karras`（非线性曲线 - SDXL 细节之王 🔍）**：
   * **特点**：前期大步流星快速勾勒大轮廓，后期放慢脚步、细嚼慢咽精雕细琢皮肤纹理与毛孔发丝。
3. **`beta` / `sgm_uniform`**：
   * **特点**：针对特定架构（如 FLUX Dev 或 SD3.5）强化高光对比度与暗部细节。

---

#### ⚠️ 避坑法则与“闭眼抄作业”黄金公式：

> [!TIP] 🎯 两大阵营闭眼搭配公式
> * **⚡ 现代极速流匹配阵营 (Z-Image-Turbo / FLUX / Wan 2.2)**：
>   👉 采样器选 **`res_multistep`** 或 **`euler`**，调度器**死死锁定 `simple`**！
> * **🏛️ 经典传统扩散阵营 (SDXL / SD 1.5)**：
>   👉 采样器选 **`dpmpp_2m`**，调度器选 **`karras`**！
> * ❌ **切忌乱搭**：不要给极速流匹配模型套用复杂的 `karras` 或高阶求解器，否则极易导致画面过曝、过度锐化或噪点残留。

---

### 5️⃣ Denoise（降噪幅度）：从零作画 vs 垫图重绘
* **`1.00`**：代表 100% 从纯噪点开始全新作画（文生图必须设为 1.00）；
* **`0.30 ~ 0.70`**：代表保留原图部分结构进行局部微调（图生图 / 垫图重绘）。

## 📦 板块四：前置算法调校配件（采样算法 AuraFlow）

在 UNet 与 K 采样器之间，还有一个前置修饰配件：

```text
【UNet 加载器】 ──(模型紫线)──> 【采样算法 (AuraFlow)】 ──(优化后模型)──> 【K 采样器】
```

* **明确归类**：属于 **【4️⃣ 画笔作画过程 (KSampler)】的前置算法修饰配件**！
* **`移位 (Shift 3.00)` 的作用**：Z-Image-Turbo 采用了现代 **Flow Matching（流匹配）** 算法。`移位 3.00` 负责调校去噪早期与晚期的注意力分配，让画面在短短 8 步内噪点消除得极其干净、写实质感极其强烈。
