## 🎛️ 采样器 (KSampler) 5 大核心参数深度透视

在 ComfyUI 的作画中枢 `K 采样器` 中，这 5 个参数决定了 AI 画家每一笔的具体画法：

```text
┌───────────────────────────────────────────────────────────┐
│                    K 采样器 (KSampler)                    │
│  ├─ 种子 (seed)               ➔ 8888 (画面的基因灵感)    │
│  ├─ 生成后控制 (control)      ➔ fixed (锁定/随机策略)    │
│  ├─ 步数 (steps)              ➔ 8 (去噪雕琢轮数)         │
│  ├─ cfg                       ➔ 1.0 (听话程度与引导尺度) │
│  ├─ 采样器名称 (sampler_name) ➔ res_multistep (画笔算法) │
│  ├─ 调度器 (scheduler)        ➔ simple (步长节奏曲线)    │
│  └─ 降噪 (denoise)            ➔ 1.00 (从零作画/垫图重绘) │
└───────────────────────────────────────────────────────────┘
```

---

### 1️⃣ Seed（随机种子）与 4 种控制策略

* **大白话**：Seed 是画面的**“基因灵感编号”**。它决定了最开始那张充满噪点的画布上，噪点的具体分布点位。
* **锁定 Seed 的意义**：只要 Seed 固定为某个数值（如 `8888`），画面的人物长相、五官比例、构图角度与光影机位就会被 **100% 锁定**！此时你可以随心修改局部提示词（如“把白猫换成黑猫”），而猫咪的姿态和背景不会发生任何跳变。

#### 💡 `生成后控制 (control_after_generate)` 4 种模式：
* **`fixed`（固定）**：死死锁定当前 Seed 数字。专用于**微调局部细节、垫图重绘与固定角色**。
* **`randomize`（随机）**：每次点击运行，系统自动抽奖换一个全新的 Seed。专用于**寻找全新灵感**。
* **`increment`（递增）**：每次运行 Seed 自动 `+1`。专用于连续批量探索微小差异。
* **`decrement`（递减）**：每次运行 Seed 自动 `-1`。

---

### 2️⃣ Steps（去噪步数）：画家的“雕琢轮数”

* **大白话**：AI 从一片纯白噪点中，拿起橡皮擦和画笔雕琢还原画面的总循环次数。
* **不同模型架构的步数规律**：
  * **Turbo / 蒸馏模型（如 Z-Image-Turbo / FLUX Schnell）**：仅需 **4 ~ 8 步** 即可完美收敛出图。多调步数（如调到 30 步）反而可能导致画面过饱和或崩坏！
  * **标准大模型（如 SDXL 1.0 / FLUX Dev）**：通常需要 **20 ~ 30 步**。
  * **步数越少** ➔ 生成速度越快；**步数适中** ➔ 细节最丰富；**步数过多** ➔ 边际效益递减，浪费算力。

---

### 3️⃣ CFG（Classifier-Free Guidance 引导尺度）：画家的“听话程度”

* **大白话**：控制 AI 画家“有多严格地遵循提示词”。
* **参数调校秘籍**：
  * **`CFG = 1.0`（极速模型标配）**：在 Z-Image-Turbo、FLUX 等新一代流匹配/蒸馏模型中，**必须固定设为 `1.0`**！这代表 AI 不需要计算负向提示词，直接依靠自身强大的模型先验全速收敛。
  * **`CFG = 6.0 ~ 8.0`（传统 SD1.5 / SDXL 标配）**：在传统模型中，数值越大，画面越贴合文字，但过大（>12）会导致画面色彩过曝、边缘焦黑。

---

### 4️⃣ Sampler Name（采样器算法）与 Scheduler（调度器）

* **采样器算法 (`sampler_name`)**：AI 去噪时的**数学微分求解器（画法流派）**。
  * `res_multistep`：专为极速蒸馏/流匹配模型设计的多步求解器，收敛极快。
  * `euler` / `euler_ancestral`：最经典、速度快、稳定性强的通用算法。
  * `dpmpp_2m` / `dpmpp_3m_sde`：传统 SDXL 常用，细节极其锐利。
* **调度器 (`scheduler`)**：决定每一步去噪时“步长衰减的节奏曲线”。
  * `simple`：平滑均匀的时间步分配，极速模型黄金搭档。
  * `karras`：在去噪中后期精雕细琢，适合人像写实。
  * `normal`：标准线性衰减。

---

### 5️⃣ Denoise（降噪幅度）：从零作画 vs 垫图重绘

* **大白话**：决定画布上保留多少旧画面，擦除多少重新画。
* **`Denoise = 1.00`（文生图默认值）**：代表 **100% 擦除**，从一张充满纯随机噪点的空白画布从零开始创作。
* **`Denoise = 0.30 ~ 0.70`（图生图 / 局部重绘）**：代表保留原图的骨架与大轮廓，只对 30%~70% 的微观噪点进行二次重绘改造。

## ⚙️ 高级预处理配件与微调算法深度拆解

在真机解包的工作流中，你还看到了两个非常核心的辅助节点，它们分别负责**算法修饰**与**负向静音**：

---

### 1. `采样算法 (AuraFlow)` 与 `移位 (Shift 3.00)`

```text
【UNet 加载器】 ──(模型紫线)──> 【采样算法 (AuraFlow)】 ──(优化后模型)──> 【K 采样器】
```

* **明确归类**：属于 **【4️⃣ 画笔作画过程 (KSampler)】的前置算法修饰配件**！
* **为什么插在中间？**：
  * Z-Image-Turbo / AuraFlow 等新一代大模型采用了 **Flow Matching（流匹配）** 算法，不同于传统扩散机制。
  * `移位 (Shift 3.00)` 是官方针对写实摄影调校的黄金参数，负责调整去噪过程中“宏观结构”与“微观细节”的算力分配倾斜，让画面在短短 8 步内噪点消除得极其干净且边缘锐利。

---

### 2. `条件零化 (ConditioningZeroOut)`：负向条件静音器

```text
【CLIP 文本编码】 ──(条件黄线)──> 【条件零化】 ──(清零负向)──> 【K 采样器: 负面条件】
```

* **明确归类**：属于 **【2️⃣ 需求翻译官】组的“负向条件静音器”**！
* **为什么需要它？**：
  * 传统 SD 1.5/SDXL 作画时，采样器每一步都需要同时计算“正向词”和“负向词”并进行差分引导（相当于每一步都要算 2 遍网络，耗时翻倍）。
  * 而 Z-Image-Turbo / FLUX 等现代 Turbo 蒸馏模型语义收敛极强，**完全不需要写繁琐的负向词**！
  * `条件零化` 节点将负向条件彻底清空（数学归零），使采样器省去一半的负向计算量，全速输出高质感画面！

## 🖨️ 画布规格与并发生产力参数

在 `空Latent图像 (SD3)` 节点中，除了宽高以外，还有一个极具威力的生产力参数：

```text
┌──────────────────────────────────────────────────────────┐
│                   空Latent图像 (SD3)                     │
│  ├─ 宽度 (width)       ➔ 1536                            │
│  ├─ 高度 (height)      ➔ 648 (21:9 电影画幅)             │
│  └─ 批量大小 (batch)   ➔ 1 (单次并发生成几张)            │
└──────────────────────────────────────────────────────────┘
```

---

### ⚠️ `批量大小 (Batch Size)` vs 右上角 `任务队列 (Queue)`

新手最容易把这两个功能搞混，它们虽然都能生成多张图片，但底层原理完全不同：

| 对比维度 | `批量大小` (Batch Size) | 右上角 `任务队列` (Queue Count) |
| :---: | :---: | :---: |
| **作画方式** | **一锅炖（显卡同时并发画多张）** | **排队跑（画完一张自动接着画下一张）** |
| **出图速度** | 🚀 极快（充分榨干显卡并发算力） | ⏳ 线性累加（时间成倍增加） |
| **显存占用** | 💥 **显存成倍暴涨！**<br>(设为 4 显存可能从 8G 飙到 16G+) | 🛡️ **显存完全不变！**<br>(永远只占 1 张图的显存) |
| **爆显存风险** | 高（显存不足容易 CUDA OOM 报错崩溃） | 零风险（极度稳健安全） |

#### 💡 双机硬件配置推荐：
* 🥇 **家用主力机 RTX 5080**：跑 Turbo 极速模型时，可将 `批量大小` 设为 **`2` 或 `4`**，**1~3 秒直接并发产出 4 张大图**，抽卡效率极高！
* 🥈 **办公挂机机 RTX 4070 12GB**：建议保持 **`批量大小 = 1`**，通过右上角添加队列（如点 10 次队列）让办公室电脑全天候挂机排队出图，绝不爆显存！
* 🎬 **视频生成时代 (Wan 2.2)**：**严禁调大批量大小，必须死死锁定为 1**（单支视频本身已包含数百帧，显存负荷极重）。
