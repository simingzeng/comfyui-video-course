# 00. ComfyUI Desktop 官方桌面版从安装到跑通第一张大片

> **真实实拍保姆级！** 本节专为 ComfyUI Desktop 官方最新版打造，手把手教你完成安装、配置全局 D 盘共享模型库、新建 MainEnv 实例、自动拉取 Z-Image-Turbo 19.27GB 模型并成功渲染第一张大片。

---

## 📥 一、 官网下载安装包（第一步）

在开始安装之前，请认准官方唯一下载入口：

* 🌐 **官方下载网址**：[https://www.comfy.org/download](https://www.comfy.org/download)
* 📦 **安装包文件**：点击页面中的 **`Download for Windows`** 按钮，下载获取 `ComfyUI_Setup.exe` 安装程序。

---

## ⚙️ 二、 安装向导 4 大步骤（真实安装流程）

双击运行下载好的 `ComfyUI_Setup.exe`，安装过程分为 4 步：

1. **安装选项**：选择 `仅为我安装` ➔ 点击 **【下一步】**。
2. **选定安装位置**：保持默认安装路径即可（此步骤仅安装约 500MB 的软件启动壳，不占空间） ➔ 直接点击 **【安装】**。
3. **自动安装依赖**：系统会自动抽取文件并安装 `Microsoft Visual C++` 等必备运行库。
4. **完成向导**：勾选 `运行 Comfy Desktop` ➔ 点击 **【完成】**。

---

## 🛡️ 三、 首次进入大厅：【全局共享模型目录前置设置】（黄金源头防爆 C 盘！）

安装完成打开软件，第一次进入暗黑紫风的 **启动大厅仪表板** 时，请**优先完成全局共享模型目录的配置**。这样以后下载的所有动辄几十 GB 的大模型都会自动存入 D 盘，彻底免除 C 盘爆满的后顾之忧！

### 📌 3 步设置全局共享模型目录：

1. **点击左上角菜单**：在大厅仪表板界面最左上角，点击三条杠 **`≡`** 菜单按钮。
2. **打开桌面端设置**：在弹出的下拉菜单中，选择 **`桌面端设置`**。
3. **设置共享模型路径**：
   * 在弹出的【桌面端设置】窗口中，点击左侧的 **`存储`** 选项卡。
   * 看右侧的 **`共享模型`** 设置项，点击 **`+ 添加目录`**（或点击文件夹图标）。
   * 选择或创建一个位于磁盘容量大的分区目录（例如：`D:\ComfyUI-Shared\models`）。
   * *效果*：以后所有实例一键下载的大模型，统统会自动全自动保存到这个 D 盘共享目录中！

---

## 🚨 四、 新建实例：【新建 MainEnv 实例 + 选跳过并安装】

完成全局共享路径设置后，回到启动大厅中央：

### 📌 新建实例 3 步走：

1. **点击【新建实例】**：鼠标左键点击大厅大大的 **`+ 新建实例`** 卡片。
2. **在【配置 Comfy Desktop】窗口**：
   * **名称（Name）**：**推荐填入 `MainEnv`**！这样在硬盘上建立的物理文件夹名就是 `MainEnv`，彻底告别默认重名困扰！
   * **安装位置（Location）**：选择 `D:\ComfyUI-Installs`，点击右下角亮黄色的 **`继续`** 按钮。
3. **在【选择入门工作流】窗口（📢 避开后台 53GB 自动下载坑！）**：
   * **千万不要点击右下角的黄色【安装】按钮！**（避免后台下载 53GB 大模型塞爆 C 盘）。
   * **请务必点击左下角的【跳过并安装】按钮！**
4. **等待解压**：软件会自动在后台进行 Python 嵌入环境解压（根据网速需耐心等待 3~5 分钟）。解压完成后会**自动直接打开作画画布**，且首次会自动弹出【模板库】窗口！

---

## 🚀 五、 顺水推舟：Z-Image-Turbo 模板一键自动下载模型，跑通第一张大片！

环境解压完成后，软件会自动打开作画画布并自动弹出 **【模板库】** 窗口。请直接顺着弹窗完成极速开局：

### 📌 官方真机 5 步极速出图指南：

#### 1. 切换选择【所有模板】
在自动弹出的模板库窗口左侧菜单中，**首先点击 `所有模板`**（或 `Popular`），顶部搜索框就会激活。

> 💡 **容错提示（如果手滑误关了模板弹窗）**：
> 不用慌！随时点击 ComfyUI 画布最左侧黑色边栏最下方的 **`模板`** 图标，即可重新打开模板库窗口。

#### 2. 搜索并载入模板
在搜索框输入 `Z-Image`，点击选择 **`Z-Image-Turbo: 文生图`** 官方模板载入画布。

#### 3. 点击【查看详情】
工作流载入后，右上角会弹出黑红色的警示框：**`发现 3 个错误 (请在运行工作流前解决这些问题)`**。点击按钮 **`查看详情`**！

#### 4. 一键拉取模型：点击【全部下载】
* 右侧侧边栏会展开【缺失模型】明细，列出 `ae.safetensors` (319MB)、`qwen_3_4b` (7.49GB) 和 `z_image_turbo_bf16` (11.46GB)。
* **直接点击最下方的蓝色按钮：`📥 全部下载 (19.27 GB)`！**
* 软件会自动在后台把这 3 个模型下载好，并自动精准安放到你先前设好的共享模型目录中。

#### 5. 渲染你的第一张 Z-Image-Turbo 极速大片！
等待 19.27GB 在后台下载归位后，报错提示消失。在提示词框中双击填入中文（如：`一个赛博朋克风格的发光城市，夜景，8k，极高画质`），点击屏幕右上角的 **`▷ 运行`** 按钮，8 步采样极速渲染出图！

## 📂 六、 权威解密：模型真实保存路径与文件夹 3 大金字塔

### 1️⃣ 下载的模型到底存放在哪里？

如果你按照【三、全局共享模型设置】将共享路径设置为了 D 盘，那么你在界面一键下载的所有大模型，都会**100% 真实存放在你的 D 盘共享仓中**：

* **官方共享模型绝对路径**（界面下载模型的真正的落地存放地）：
  👉 **`D:\ComfyUI-Shared\models\`**
* **实例私有模型路径**（你自己手动拖入的私有测试模型）：
  👉 **`D:\ComfyUI-Installs\MainEnv\ComfyUI\models\`**

---

### 2️⃣ 3 大核心目录金字塔结构（日常使用只需记住这 3 个）：

作为使用者，你完全不需要理会繁杂的系统代码文件夹，只需要记住以下 3 个核心位置的分工：

```text
D:\ (你的 D 盘大分区)
├── ComfyUI-Shared/              <-- 1. 共享模型大本营（最核心！界面下载的所有大模型全在这里）
│   └── models/
│       ├── text_encoders/       <-- 存放语言/文本编码器 (如 qwen_3_4b)
│       ├── diffusion_models/    <-- 存放生成主模型 (如 z_image_turbo / flux-2-klein)
│       ├── vae/                 <-- 存放图像解码器 (如 ae.safetensors)
│       ├── checkpoints/         <-- 存放传统整合大模型 (如 SDXL 1.0)
│       ├── loras/               <-- 存放风格/角色微调模型 (LoRA)
│       └── controlnet/          <-- 存放姿态控制模型 (ControlNet)
│
└── ComfyUI-Installs/MainEnv/ComfyUI/   <-- 2 & 3. 你的 MainEnv 实例根目录
    ├── custom_nodes/            <-- 2. 插件安装区（你安装的所有第三方节点扩展代码都在这里）
    └── output/                  <-- 3. 成果产出区（你每次点击“运行”生成的图片，自动在这里存好！）
```
