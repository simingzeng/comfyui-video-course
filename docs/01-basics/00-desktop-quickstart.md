# 00. ComfyUI Desktop 官方桌面版从安装到跑通第一张大片

> **真实实拍保姆级！** 本节专为 ComfyUI Desktop 官方最新版打造，手把手教你完成安装、看懂官方默认存储机制与自定义迁移、新建长期主力 `MainEnv` 实例、自动拉取 Z-Image-Turbo 19.27GB 模型并成功渲染第一张大片。

---

## 📥 一、 官网下载安装包（第一步）

在开始安装之前，请认准官方唯一下载入口：

* 🌐 **官方下载网址**：[https://www.comfy.org/download](https://www.comfy.org/download)
* 📦 **安装包文件**：点击页面中的 **`Download for Windows`** 按钮，下载获取 `ComfyUI_Setup.exe` 安装程序。

---

## ⚙️ 二、 安装向导 4 大步骤（真实安装流程）

双击运行下载好的 `ComfyUI_Setup.exe`，安装过程分为 4 步：

1. **安装选项**：选择 `仅为我安装` ➔ 点击 **【下一步】**。
2. **选定安装位置**：保持默认安装路径即可（此步骤仅安装约 500MB 的启动壳程序，位于 `C:\Users\<你的用户名>\AppData\Local\Programs\Comfy Desktop\`，不占空间） ➔ 直接点击 **【安装】**。
3. **自动安装依赖**：系统会自动抽取文件并安装 `Microsoft Visual C++` 等必备运行库。
4. **完成向导**：勾选 `运行 Comfy Desktop` ➔ 点击 **【完成】**。

---

## 🛡️ 三、 首次进入大厅：【存储设置全景解析（官方默认 vs D盘防爆）】

安装完成打开软件，第一次进入暗黑紫风的 **启动大厅仪表板** 时，建议先了解 ComfyUI Desktop 的存储架构：

```text
点击左上角三条杠 ≡ 菜单 ➔ 【桌面端设置】 ➔ 点击左侧【存储】选项卡
```

打开后你将看到官方默认配置的三大核心路径：

| 存储项目 | 官方默认物理路径 | 核心作用说明 |
| :--- | :--- | :--- |
| **共享模型** | `C:\Users\<你的用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Shared\models` | 所有通过界面一键下载的大模型存放地（最占空间） |
| **共享输入** | `C:\Users\<你的用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Shared\input` | 垫图、参考图等输入素材目录 |
| **共享输出** | `C:\Users\<你的用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Shared\output` | 🚨 **所有运行生成的图片、视频最终落盘目录！** |

::: details 💡 选择你的存储策略：直接默认还是改到 D 盘？{open}

* **方案 A：官方默认流（省心极速，推荐 C 盘空闲 > 100GB 用户）**：
  * **直接保持默认，无需做任何修改！**
  * 官方桌面版已为你全自动建好 `ComfyUI-Shared` 文件夹，顺畅直接使用即可。
* **方案 B：D 盘迁移流（防爆 C 盘，推荐 C 盘空间紧张用户）**：
  * 在【共享模型】右侧点击 **`+ 添加共享目录`**（或点击文件夹图标），将其指向磁盘空间充裕的分区（例如新建 `D:\ComfyUI-Shared\models`）；
  * 同样可将【共享输出】指向 `D:\ComfyUI-Shared\output`；
  * 这样未来下载的所有几十 GB 大模型与海量渲染成片都会自动存入 D 盘。

:::

## 🚨 四、 新建实例：【新建主力 MainEnv 实例 + 选跳过并安装】

完成存储了解后，回到启动大厅中央：

### 📌 新建实例 3 步走：

1. **点击【新建实例】**：鼠标左键点击大厅大大的 **`+ 新建实例`** 卡片。
2. **在【配置 Comfy Desktop】窗口**：
   * **名称（Name）**：**填入 `MainEnv`**！这个实例是你后续整个系列教程（包括 FLUX、Wan 2.2、ControlNet、分镜短片等）的**长期主力母舰环境**，后续无需重复新建！
   * **安装位置（Location）**：
     * 保持默认：`C:\Users\<你的用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Installs`
     * 或自定义改为：`D:\ComfyUI-Installs`
   * 点击右下角亮黄色的 **`继续`** 按钮。
3. **在【选择入门工作流】窗口（📢 避开后台 53GB 自动下载坑！）**：
   * **千万不要点击右下角的黄色【安装】按钮！**（避免后台下载 53GB 大模型塞爆磁盘）。
   * **请务必点击左下角的【跳过并安装】按钮！**
4. **等待解压**：软件会自动在后台进行 Python 独立环境解压（根据硬件与网速需耐心等待 3~5 分钟）。解压完成后会**自动直接打开作画画布**，且首次会自动弹出【模板库】窗口！

## 🚀 五、 顺水推舟：Z-Image-Turbo 模板一键自动下载模型，跑通第一张大片！

环境解压完成后，软件会自动打开作画画布并自动弹出 **【模板库】** 窗口。请直接顺着弹窗完成极速开局：

### 📌 官方真机 5 步极速出图指南：

#### 1. 切换选择【所有模板】
在自动弹出的模板库窗口左侧菜单中，**首先点击 `所有模板`**（或 `Popular`），顶部搜索框就会激活。

> 💡 **容错提示（如果手滑误关了模板弹窗）**：  
> 不用慌！随时点击 ComfyUI 画布最左侧黑色边栏最下方的 **`模板`** 图标，即可重新打开模板库窗口。

#### 2. 搜索并载入模板
在搜索框输入 `Z-Image`，点击选择 **`Z-Image-Turbo: 文生图`** 官方模板载入画布。

#### 3. 点击【查看详情】
工作流载入后，右上角会弹出黑红色的警示框：**`发现 3 个错误 (请在运行工作流前解决这些问题)`**。点击按钮 **`查看详情`**！

#### 4. 一键拉取模型：点击【全部下载】
* 右侧侧边栏会展开【缺失模型】明细，列出 `ae.safetensors` (319MB)、`qwen_3_4b` (7.49GB) 和 `z_image_turbo_bf16` (11.46GB)。
* **直接点击最下方的蓝色按钮：`📥 全部下载 (19.27 GB)`！**
* 软件会自动在后台把这 3 个模型下载好，并自动精准安放到你设定的共享模型目录（`ComfyUI-Shared\models`）中。

#### 5. 渲染你的第一张 Z-Image-Turbo 极速大片！
等待 19.27GB 在后台下载归位后，报错提示消失。在提示词框中双击填入中文（如：`一个赛博朋克风格的发光城市，夜景，8k，极高画质`），点击屏幕右上角的 **`▷ 运行`** 按钮，8 步采样极速渲染出图！

## 📂 六、 权威解密：真实保存路径与文件夹架构

### 1️⃣ 下载的模型与生成的图片到底保存在哪里？

ComfyUI Desktop 官方桌面版采用了**“实例运行环境”与“全局共享资产”彻底分离**的现代化设计：

* **大模型真实存放路径**（界面下载的所有大模型集中地）：
  * 默认路径：`C:\Users\<你的用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Shared\models\`
  * 自定义路径：`D:\ComfyUI-Shared\models\`
* **图片与视频真实落盘路径**（点击“运行”后生成的产物）：
  * 默认路径：👉 **`C:\Users\<你的用户名>\AppData\Local\Comfy-Desktop\ComfyUI-Shared\output\`**
  * 自定义路径：👉 `D:\ComfyUI-Shared\output\`
  * 🚀 **1秒直达快捷技巧**：在桌面端左上角打开【桌面端设置 ➔ 存储】，直接点击【共享输出】右侧的 **📁 文件夹图标**，即可瞬间在文件资源管理器中打开成果文件夹！

---

### 2️⃣ 核心目录金字塔结构（日常使用只需记住这 3 层）：

无论你选择默认 C 盘还是自定义 D 盘，目录结构的分工始终完全一致：

```text
Comfy-Desktop 根目录/
├── ComfyUI-Shared/                      <-- 1. 共享资产中心（最核心！与所有实例解耦）
│   ├── models/                          <-- 模型大本营（界面下载的所有几十 GB 模型都在这里）
│   │   ├── text_encoders/               <-- 语言/文本编码器 (如 qwen_3_4b)
│   │   ├── diffusion_models/            <-- 生成主扩散模型 (如 z_image_turbo / flux1-dev)
│   │   ├── vae/                         <-- 图像编解码器 (如 ae.safetensors)
│   │   ├── checkpoints/                 <-- 传统整合模型 (如 SDXL 1.0)
│   │   ├── loras/                       <-- 微调风格模型 (LoRA)
│   │   └── controlnet/                  <-- 控制网模型 (ControlNet)
│   ├── input/                           <-- 共享输入素材（垫图、参考图）
│   └── output/                          <-- 🚨 共享成果产出区（所有生成的图片与视频都在这里！）
│
└── ComfyUI-Installs/MainEnv/ComfyUI/    <-- 2. 你的 MainEnv 实例母舰（运行环境）
    ├── custom_nodes/                    <-- 插件代码区（所有安装的第三方扩展节点都在这里）
    └── models/                          <-- 实例私有模型区（仅用于测试极特殊的私有模型，平时留空）
```

---

::: details ❓ 实例管理与存储常见困惑权威解答 (FAQ)

1. **阶段 0 的 `MainEnv` 后面还要用吗？可以删掉吗？**
   * **绝对不要删！** `MainEnv` 是你后续所有阶段（FLUX、Wan 2.2、ControlNet、分镜短片、声音驱动等）的**唯一通用主力母舰**。所有插件（如 ComfyUI-Manager、视频处理节点）都会装入它的 `custom_nodes` 中。换模型只需在画布里切换工作流，无需为每个模型重建实例。
2. **为什么在 `MainEnv\ComfyUI\output` 文件夹里找不到我生成的图片？**
   * 因为 ComfyUI Desktop 官方桌面版采用了**全局共享输出机制**！所有渲染出的图片和视频都会统一写入【共享输出 (Shared output)】文件夹（即 `ComfyUI-Shared\output\`），实例内部的 output 仅保留为空占位符。
3. **如果误建了多余实例（如 Test、ComfyUI-1），如何安全删除？**
   * **第 1 步**：在大厅仪表板左上角点击 `≡` 菜单 ➔ 选择【实例列表】（或关闭画布返回大厅）；
   * **第 2 步**：找到需要清理的多余实例卡片，点击右上角的 **`···`**（三点菜单），选择 **【删除实例 (Delete)】** 并确认；
   * **第 3 步（定心丸）**：删除实例只会抹去该实例的 Python 运行时和插件代码，**`ComfyUI-Shared\models\` 里的所有几十 GB 大模型 100% 毫发无伤**！
4. **如何释放磁盘空间以清理不再需要的模型？**
   * **方式 A（界面管理）**：在桌面端左下角点击【⚙️ 桌面端设置 ➔ 存储 ➔ 共享模型】，查看各模型体积并点击右侧垃圾桶删除。
   * **方式 B（物理删除）**：直接打开文件管理器进入 `ComfyUI-Shared\models\` 对应子文件夹，手动删除对应的 `.safetensors` 文件即可。
5. **重装系统或更换电脑，几十 GB 的模型需要重新下载吗？**
   * **完全不需要！** 只要将你的 `ComfyUI-Shared\models\` 目录备份到移动硬盘或大容量分区，重装软件后在【存储】设置中重新添加指向该文件夹，所有模型瞬间秒级识别恢复！

:::
