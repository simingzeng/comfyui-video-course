# 00. ComfyUI Desktop 官方桌面版安装与启动大厅指南

> **写给真正的零基础！** 本节专为 **ComfyUI Desktop 官方桌面版（v0.32+ 最新版）** 打造，手把手教你如何从软件启动大厅一键进入作画画布。

---

## 🚨 1. 认识 ComfyUI Desktop 启动大厅

当你双击桌面的 **ComfyUI** 图标后，软件会先弹出一个带有暗黑紫风的**启动大厅界面**：

![ComfyUI Desktop 桌面启动器指南](./launcher-guide.png)

### 💡 新手保姆级进入指引：
1. **千万不用点击“+ 新建实例”**：软件首次安装后，已经为你自动配置好了一个默认的本地开发环境（如 `ComfyUI-20260812`）。
2. **一键进入画布（两种方法）**：
   * **方法 1（最快）**：鼠标直接点击大厅中央的 **`ComfyUI-20260812` 本地实例卡片**。
   * **方法 2**：点击界面右下角醒目的蓝色 **`▶ 启动`** 按钮（如上图箭头所示）。
3. 稍微等待 3~5 秒，系统就会正式加载并自动跳转进入我们的**节点作画画布**！

---

## 🛠️ 2. 认识 ComfyUI 画布与鼠标键盘基本操作

当成功进入画布后，你会看到带有网格背景与彩色连线框框的黑盒作画台。你可以像操控游戏地图一样控制它：

* **平移画布**：按住鼠标左键并拖拽空白处。
* **放大/缩小**：向上或向下滑动鼠标滚轮。
* **修改文字**：鼠标左键双击节点内的英文文本框即可直接修改。
* **连线拉线**：鼠标左键按住节点边缘的彩色小圆点，拖出一条线拉到另一个相同颜色的小圆点上。

---

## 🖐️ 3. 手把手教你跑通第一张图（4 步极简实操指南）

跟着下方的 **实操标注大图**，用鼠标一步步点击：

![ComfyUI桌面端操作指南](./desktop-guide.png)

### 📌 详细步骤：
1. **找到正向提示词框**：在画布左侧找到标题为 `CLIP Text Encode (Prompt)` 的大框框。
2. **双击修改文字**：双击框框内的文字，按 `Ctrl+A` 删除旧文字，粘贴：`a futuristic cyberpunk city, neon lights, 8k`。
3. **点击 Queue Prompt**：鼠标点击右侧控制面板上的大按钮 **`Queue Prompt`**（或按快捷键 `Ctrl + Enter`）。
4. **生成与保存**：观察节点四周亮起绿色边框，最后在 `Save Image` 节点中生成出第一张赛博发光城市大片！右键点击图片即可保存。
