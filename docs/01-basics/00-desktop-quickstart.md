# 00. ComfyUI Desktop 官方桌面版从安装到跑通第一张大片

> **真实实拍保姆级！** 本节专为 ComfyUI Desktop 官方最新版打造，手把手教你完成安装、新建 MainEnv 实例、自动拉取 Z-Image-Turbo 19.27GB 模型并成功渲染第一张大片。

---

## 📥 一、 官网下载安装包（第一步）

在开始安装之前，请认准官方唯一下载入口：

* 🌐 **官方下载网址**：[https://www.comfy.org/download](https://www.comfy.org/download)
* 📦 **安装包文件**：点击页面中的 **`Download for Windows`** 按钮，下载获取 `ComfyUI_Setup.exe` 安装程序。

---

## ⚙️ 二、 安装向导 4 大步骤（真实安装流程）

双击运行下载好的 `ComfyUI_Setup.exe`，安装过程分为 4 步：

1. **安装选项**：选择 `仅为我安装` ➔ 点击 **【下一步】**。
2. **选定安装位置**：保持默认安装路径即可（此步骤仅安装约 500MB 的软件启动壳，不占空间） ➔ 直接点击 **【安装】**。
3. **自动安装依赖**：系统会自动抽取文件并安装 `Microsoft Visual C++` 等必备运行库。
4. **完成向导**：勾选 `运行 Comfy Desktop` ➔ 点击 **【完成】**。

---

## 🚨 三、 首次打开大厅：【新建实例 + 选跳过并安装】

首次全新安装成功后，打开的 **Comfy Desktop 启动大厅** 中央是空白的，只有 **`+ 新建实例`** 和 **`Comfy Cloud`** 两个卡片：

### 📌 新建实例 3 步走：

1. **点击【新建实例】**：鼠标左键点击大厅左侧大大的 **`+ 新建实例`** 卡片。
2. **在【配置 Comfy Desktop】窗口（📢 核心路径与命名黄金避坑点！）**：
   * **名称（Name）**：**推荐填入 `MainEnv`**！这样在硬盘上建立的物理文件夹名就是 `MainEnv`，彻底告别默认重名困扰！
   * **安装位置（Location —— ⚠️ 真正的硬盘空间大户！）**：默认在 C 盘。**请务必点击右侧的【浏览...】按钮，修改为磁盘容量大的分区（例如：`D:\ComfyUI-Installs`）！**
   * *为什么*：因为后续下载的所有动辄十几 GB ~ 几十 GB 的大模型、Python 虚拟环境以及你生成的所有画作成果，**全都会默认保存在这个目录中**！
   * **操作**：配置好名称和 D 盘路径后，点击右下角亮黄色的 **`继续`** 按钮。
3. **在【选择入门工作流】窗口（📢 避开后台 53GB 自动下载坑！）**：
   * **千万不要点击右下角的黄色【安装】按钮！**（避免后台下载 53GB 大模型塞爆 C 盘）。
   * **请务必点击左下角的【跳过并安装】按钮！**
4. **等待解压**：软件会自动在后台进行 Python 嵌入环境解压（根据网速需耐心等待 3~5 分钟）。解压完成后会**自动直接打开作画画布**，且首次会自动弹出【模板库】窗口！

---

## 🚀 四、 顺水推舟：Z-Image-Turbo 模板一键自动下载模型，跑通第一张大片！

环境解压完成后，软件会自动打开作画画布并自动弹出 **【模板库】** 窗口。请直接顺着弹窗完成极速开局：

### 📌 官方真机 5 步极速出图指南：

#### 1. 切换选择【所有模板】
在自动弹出的模板库窗口左侧菜单中，**首先点击点击 `所有模板`**（或 `Popular`），顶部搜索框就会激活。

> 💡 **容错提示（如果手滑误关了模板弹窗）**：
> 不用慌！随时点击 ComfyUI 画布最左侧黑色边栏最下方的 **`模板`** 图标，即可重新打开模板库窗口。

#### 2. 搜索并载入模板
在搜索框输入 `Z-Image`，点击选择 **`Z-Image-Turbo: 文生图`** 官方模板载入画布。

#### 3. 点击【查看详情】
工作流载入后，右上角会弹出黑红色的警示框：**`发现 3 个错误 (请在运行工作流前解决这些问题)`**。点击按钮 **`查看详情`**！

#### 4. 一键拉取模型：点击【全部下载】
* 右侧侧边栏会展开【缺失模型】明细，列出 `ae.safetensors` (319MB)、`qwen_3_4b` (7.49GB) 和 `z_image_turbo_bf16` (11.46GB)。
* **直接点击最下方的蓝色按钮：`📥 全部下载 (19.27 GB)`！**
* 软件会自动在后台把这 3 个模型下载好并精准自动安放到 `models/` 的对应子目录中。

#### 5. 渲染你的第一张 5080 震撼大片！
等待 19.27GB 在后台下载归位后，报错提示消失。在提示词框中双击填入中文（如：`一个赛博朋克风格的发光城市，夜景，8k，极高画质`），点击屏幕右上角的 **`▷ 运行`** 按钮，8 步采样极速渲染出图！

---

#### 📂 5. 19.27GB 模型真实存放位置与【官方全局模型共享机制】解密

##### ❓ 为什么新建了 `MainEnv` 实例后，模型没有丢失且能直接运行？
因为 ComfyUI Desktop 采用了极度优雅的 **【全局模型共享仓库 (Global Shared Models Storage)】** 机制：

* **官方全局共享模型仓**（所有实例共享，防重复占用）：
  👉 **`C:\Users\用户名\AppData\Local\Comfy-Desktop\models\`**
* **实例独立目录**（你自己手动放的私有模型）：
  👉 **`D:\ComfyUI-Installs\MainEnv\ComfyUI\models\`**

##### 💡 底层工作逻辑：
当你首次通过界面一键下载 Z-Image-Turbo 时，19.27GB 的模型文件会被**统一保存在全局仓库 `Comfy-Desktop\models\` 对应子目录中**（包含 `text_encoders/qwen_3_4b` 和 `diffusion_models/z_image_turbo_bf16`）。

当你新建 `MainEnv` 或其他任何新实例时，ComfyUI Desktop 会自动在后台将全局仓库挂载进来。因此**新实例完全不需要重复下载 19.27GB 的模型，直接就能识别并流畅运行出图！**

### 2️⃣ 3 大核心目录金字塔规律（日常使用只需记这 3 个）：
虽然 ComfyUI 根目录下有许多代码文件夹，但作为使用者，你**完全不需要管系统代码文件夹**，只需要记住这 3 个最核心的目录：

```text
MainEnv/ComfyUI (内核根目录)
├── models/              <-- 1. 模型大本营（所有几GB~几十GB的模型全存这里）
│   ├── text_encoders/   <-- 语言/文本编码器 (如 qwen_3_4b)
│   ├── diffusion_models/<-- 生成主模型 (如 z_image_turbo / flux-2-klein)
│   ├── vae/             <-- 图像解码器 (如 ae.safetensors)
│   ├── checkpoints/     <-- 传统整合大模型 (如 SDXL 1.0)
│   ├── loras/           <-- 风格/角色微调模型 (LoRA)
│   └── controlnet/      <-- 姿态控制模型 (ControlNet)
├── custom_nodes/        <-- 2. 插件安装区（你安装的所有第三方节点代码全在这里）
└── output/              <-- 3. 成果产出区（你每次点击“运行”生成的图片，全部自动存在这里！）
```
