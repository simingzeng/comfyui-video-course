# 00. ComfyUI Desktop 官方桌面版从安装、模型配置到启动全流程

> **真实实拍保姆级！** 本节专为 ComfyUI Desktop 官方最新版打造，手把手教你完成安装、新建实例、放置第一个 Checkpoint 大模型并成功出图。

---

## 📥 一、 官网下载安装包（第一步）

在开始安装之前，请认准官方唯一下载入口下载安装程序：

* 🌐 **官方下载网址**：[https://www.comfy.org/download](https://www.comfy.org/download)
* 📦 **安装包文件**：点击页面中的 **`Download for Windows`** 按钮，下载获取 `ComfyUI_Setup.exe` 安装程序。

---

## ⚙️ 二、 安装向导 4 大步骤（真实安装流程）

运行下载好的 `ComfyUI_Setup.exe`，安装过程分为 4 步：

1. **安装选项**：选择 `仅为我安装` ➔ 点击 **【下一步】**。
2. **选定安装位置**：保持默认安装路径即可（此步骤仅安装约 500MB 的软件启动壳，不占空间） ➔ 直接点击 **【安装】**。
3. **自动安装依赖**：系统会自动抽取文件并安装 `Microsoft Visual C++` 等必备运行库。
4. **完成向导**：勾选 `运行 Comfy Desktop` ➔ 点击 **【完成】**。

---

## 🚨 二、 首次打开大厅：【新建实例 + 选跳过并安装】

首次全新安装成功后，打开的 **Comfy Desktop 启动大厅** 中央是空白的，只有 **`+ 新建实例`** 和 **`Comfy Cloud`** 两个卡片：

### 📌 新建实例 3 步走：

1. **点击【新建实例】**：鼠标左键点击大厅左侧大大的 **`+ 新建实例`** 卡片。
2. **在【配置 Comfy Desktop】窗口（📢 核心路径与命名黄金避坑点！）**：
   * **名称（Name）**：**推荐填入 `MainEnv`**！这样在硬盘上建立的物理文件夹名就是 `MainEnv`，彻底告别默认重名困扰！
   * **安装位置（Location —— ⚠️ 真正的硬盘空间大户！）**：默认在 C 盘。**请务必点击右侧的【浏览...】按钮，修改为磁盘容量大的分区（例如：`D:\ComfyUI-Installs`）！**
   * *为什么*：因为后续下载的所有动辄十几 GB ~ 几十 GB 的大模型（如 Z-Image 19.27GB）、Python 虚拟环境以及你生成的所有画作成果，**全都会默认保存在这个目录中**！
   * **操作**：配置好名称和 D 盘路径后，点击右下角亮黄色的 **`继续`** 按钮。
3. **在【选择入门工作流】窗口（📢 避开后台 53GB 自动下载坑！）**：
   * **千万不要点击右下角的黄色【安装】按钮！**（避免后台下载 53GB 大模型塞爆 C 盘）。
   * **请务必点击左下角的【跳过并安装】按钮！**
4. **等待解压**：软件会自动在后台进行 Python 嵌入环境解压（根据网速需耐心等待 3~5 分钟）。解压完成后会**直接自动打开作画画布**，且首次会弹出【模板库】窗口。

#### ❓ 7. 揭秘文件夹底层逻辑：为什么会有两个 ComfyUI？落地方案是什么？

##### 1️⃣ 为什么路径里会出现重复的 `ComfyUI\ComfyUI`？
这是官方 Desktop 的**架构层级设计**：
* **外层 `ComfyUI-Installs\ComfyUI\`** ➔ 这是 **【实例容器名】**（就是你在启动大厅新建的实例名字，默认叫 ComfyUI）。
* **内层 `...\ComfyUI\ComfyUI\`** ➔ 这是 **【内核代码根目录】**（从 GitHub 官方仓库拉下来的实际代码与模型存放地）。

##### 💡 告别路径重名困扰：如何让物理磁盘文件夹也叫 `MainEnv`？
* **现象说明**：在大厅中使用【更多 ∧】➔【重命名】修改名字后，改的是界面展示的**“外号/别名”**。为了防止破坏已经安装好的 Python 虚拟环境与路径，软件不会物理修改 Windows 硬盘上的文件夹名字。
* **物理改名方法**：如果希望磁盘上的真实文件夹也显示为 `ComfyUI-Installs\MainEnv\ComfyUI\`，只需在启动大厅点击 **`+ 新建实例`** 时，在**【名称】**输入框中直接填写 `MainEnv`！这样物理文件夹就会从诞生那一刻起直接命名为 `MainEnv`。

##### 2️⃣ 文件落地的 3 层金字塔规律（日常使用只需记这 3 个）：
虽然目录看似繁杂，但作为使用者，你**完全不需要管系统代码文件夹**，只需要记住这 3 个最重要的核心目录：

```text
ComfyUI (内核根目录)
├── models/              <-- 1. 模型资产库（最核心！按类型存放大模型、VAE、CLIP、LoRA）
│   ├── text_encoders/   <-- 语言/文本编码器 (如 qwen_3_4b)
│   ├── diffusion_models/<-- 生成主模型 (如 z_image_turbo / flux-2-klein)
│   ├── vae/             <-- 图像解码器 (如 ae.safetensors)
│   ├── checkpoints/     <-- 传统整合大模型 (如 SDXL 1.0)
│   ├── loras/           <-- 风格/角色微调模型 (LoRA)
│   └── controlnet/      <-- 姿态控制模型 (ControlNet)
├── custom_nodes/        <-- 2. 插件安装区（所有第三方节点插件代码都在这里）
└── output/              <-- 3. 成果产出区（你每次点击“运行”生成的图片，全部自动保存在这里！）
```
