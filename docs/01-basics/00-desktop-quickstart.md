# 00. ComfyUI Desktop 官方桌面版从安装、模型配置到启动全流程

> **真实实拍保姆级！** 本节专为 ComfyUI Desktop 官方最新版打造，手把手教你完成安装、新建实例、放置第一个 Checkpoint 大模型并成功出图。

---

## ⚙️ 一、 安装向导 4 大步骤（真实安装流程）

运行下载好的 `ComfyUI_Setup.exe`，安装过程分为 4 步：

1. **安装选项**：选择 `仅为我安装` ➔ 点击 **【下一步】**。
2. **选定安装位置**：建议把路径修改到磁盘大的分区（例如：`D:\Programs\Comfy Desktop`） ➔ 点击 **【安装】**。
3. **自动安装依赖**：系统会自动抽取文件并安装 `Microsoft Visual C++` 等必备运行库。
4. **完成向导**：勾选 `运行 Comfy Desktop` ➔ 点击 **【完成】**。

---

## 🚨 二、 首次打开大厅：【新建实例 + 选跳过并安装】

首次全新安装成功后，打开的 **Comfy Desktop 启动大厅** 中央是空白的，只有 **`+ 新建实例`** 和 **`Comfy Cloud`** 两个卡片：

### 📌 新建实例 3 步走：

1. **点击【新建实例】**：鼠标左键点击大厅左侧大大的 **`+ 新建实例`** 卡片。
2. **在【配置 Comfy Desktop】窗口**：安装位置建议选 D 盘，点击右下角亮黄色的 **`继续`** 按钮。
3. **在【选择入门工作流】窗口（📢 核心避坑点！）**：
   * **千万不要点击右下角的黄色【安装】按钮！**（避免后台下载 53GB 大模型塞爆 C 盘）。
   * **请务必点击左下角的【跳过并安装】按钮！**
4. **等待解压**：软件会自动在后台进行 Python 嵌入环境解压（根据网速需耐心等待 3~5 分钟）。解压完成后会**直接自动打开作画画布**，且首次会弹出【模板库】窗口。

## 📦 三、 如何安装与放置你的第一个 Checkpoint 大模型

因为我们前面选择了“跳过并安装”，所以此时画布上还没有预装大模型。要成功文生图，必须先放一个 **`Checkpoint 大模型 (.safetensors)`**。

### 📌 模型放置与安装 3 步法：

#### 1. 认识模型应该放哪里（核心路径）
在 ComfyUI 中，所有负责文生图的大模型都统一存放在：
👉 **`ComfyUI 安装目录/models/checkpoints/`** 文件夹中！

#### 2. 根据你的显卡配置选择适配模型与优化参数

| 显卡/硬件配置 | 推荐主攻模型 | 部署/优化建议 |
| :--- | :--- | :--- |
| **8G 显存** (GTX 1660 / RTX 2060) | SD 1.5 / LCM 轻量模型 | 启动必加 `--lowvram` |
| **12G/16G 显存** (RTX 4070 / 4060Ti) | **SDXL 1.0** / **FLUX.1-schnell (GGUF)** | 配置 `--lowvram`，适合挂机批处理与 4K 超分 |
| **16G/24G 显存** (RTX 5080 / 4090) | **FLUX.1-dev (原生 FP16)** / **Wan 2.1 视频** | 原生高精度渲染、图生视频关键帧与高清导出 |
| **多卡/48G+ 显存** (RTX 6000 / A100 多卡) | 原生 4K FLUX / 多卡 **Wan 2.1** 长视频 | ComfyUI-Distributed 多卡并行与 TensorRT 加速 |

#### 3. 实战案例：以 FLUX.1-dev 为例，如何安装到 ComfyUI？

安装大模型有 **2 种最主流的方法**（优先推荐方法一）：

##### 🌟 方法一：在 ComfyUI Desktop 软件内【模型大厅】一键下载（官方原生法）
> ⚠️ **新手避坑说明**：在最新版 ComfyUI Desktop 中，右上角的 `管理扩展功能` 仅用于安装插件代码（只有“节点包/节点”选项）。**真正的官方大模型下载入口在软件主侧边栏的【模型】大厅中**。

1. **进入模型大厅**：关掉弹窗，在 ComfyUI 主界面最左侧的黑色侧边栏（或点击左上角 `C` 标志返回启动大厅），点击 **`模型` (Models)** 菜单页。
2. **搜索 FLUX 模型**：在【模型】大厅的搜索框中输入 `FLUX.1-dev` 或 `FLUX`。
3. **一键安装**：找到对应的 `.safetensors` 模型卡片，点击 **`Install` (安装)**。
4. **自动下载放置**：系统会自动在后台将模型下载并放入 `models/unet/` 或 `models/checkpoints/` 目录中，下载完成后直接可用！

##### 📦 方法二：手动下载后复制到文件夹（适合大文件/网络不稳定）
FLUX.1-dev 涵盖以下关键文件，手动下载后请按以下目录存放：
* **UNet 模型文件**（`flux1-dev.safetensors`）➔ 放入 **`models/unet/`** 或 `models/checkpoints/`
* **CLIP 文本编码器**（`t5xxl_fp16.safetensors` 与 `clip_l.safetensors`）➔ 放入 **`models/clip/`**
* **VAE 解码器**（`ae.safetensors`）➔ 放入 **`models/vae/`**

放好后，在 ComfyUI 节点菜单中点击 **刷新 (Refresh)** 即可直接调用。

#### 3. 挂载本地已有模型（如果你硬盘里已有模型）
如果你的 5080/4070 电脑其他盘里已经有 SDWebUI 或 ComfyUI 模型，可以直接在 ComfyUI 根目录的 `extra_model_paths.yaml` 中配置旧模型路径，无需重复下载！

## 🖱️ 四、 认识 ComfyUI 画布与加载工作流

### 💡 如何打开【模板库】载入 5 大基础节点？

1. 看你屏幕最左边的黑色侧边栏，点击**最下方**的图标 **【模板】**（鼠标悬停会显示“模板”二字）。
2. 在弹出的窗口左侧菜单中，点击 **`节点基础`**（或选择 `图像` ➔ `文生图`）。
3. 点击选中的节点模版（或直接将教程的 [📥 01-default-workflow.json](/01-default-workflow.json) 拖入画布），标准的 5 大核心节点就会瞬间全部平铺在你的画布上了！

## 🖐️ 五、 手把手教你跑通第一张图（4 步实操指南）

请跟着下方的 **实操标注大图**，用鼠标一步步点击：

![ComfyUI桌面端操作指南](./desktop-guide.png)

### 📌 详细步骤：
1. **选择你刚刚下载的模型**：在最左侧的 `Load Checkpoint` 节点的下拉菜单中，点击选择你刚放进 `models/checkpoints/` 里的 `.safetensors` 模型。
2. **修改正向提示词**：在画布左侧找到标题为 `CLIP Text Encode (Prompt)` 的正向提示词框，双击修改文字为：`a futuristic cyberpunk city, neon lights, 8k`。
3. **点击【▷ 运行】按钮**：鼠标点击屏幕右上角的蓝框大按钮 **`▷ 运行`**（或按快捷键 `Ctrl + Enter`）。
4. **生成与保存**：观察节点四周亮起绿色边框，最后在 `Save Image` 节点中生成出第一张赛博发光城市大片！右键点击图片即可保存。
