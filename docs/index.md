## 🗺️ 8 大阶段全景能力进阶图谱

```text
阶段 0：真正理解 ComfyUI ➔ 原理、参数透视、Shared models 存储与文件落地点
阶段 1：静态图第一帧     ➔ FLUX.2 构图、LoRA 角色锁定、ControlNet 姿态、Inpaint 精修
阶段 2：第一次视频生成   ➔ Wan 2.2 5B/14B 文生视频与让照片自然动起来 (I2V)
阶段 3：视频可控生成     ➔ 首尾帧 (FLF2V)、Fun Camera 运镜、Fun Control 结构、动作迁移
阶段 4：短片大作业实战   ➔ 多镜头人物一致性 ➔ 从分镜表到 30 秒完整短片创作
阶段 5：声音驱动表演     ➔ AI 配音准备 ➔ Wan 2.2 S2V 音频驱动口型与表演
阶段 6：影视后期流水线   ➔ SAM 2 抠像 ➔ RIFE 60fps 丝滑插帧 ➔ 4K 超分 ➔ FFmpeg
阶段 7：双机自动化工厂   ➔ 5080 主力攻坚 + 4070 挂机无人值守 (ComfyUI API + Python)
阶段 8：高级 3D 专题     ➔ Depth 空间感 ➔ 多视角环视 ➔ 3D Mesh 导出 ➔ Blender 混合流
```
